# arXiv Explorer

> Semantic search across research papers with AI summaries — no login required

## What is arXiv Explorer?

arXiv Explorer indexes research papers from arXiv.org and provides instant semantic search powered by embeddings (BGE base v1.5) and AI-generated summaries (Llama 3.1 via Cloudflare Workers AI). Find papers by meaning, not just keywords.

**Live app:** https://arxivexplorer.workers.dev (or your deployment URL)

## What You Can Do

- **Semantic Search** — Natural language queries, not keyword matching
- **AI Summaries** — LLM-generated 2-3 sentence paper summaries
- **Topic Browse** — Explore by ML/NLP/CV/Physics categories
- **Author Search** — Find all papers by specific researchers
- **Paper Compare** — Side-by-side diff of two papers
- **Citation Tracking** — See what papers cite what
- **Reproducibility Claims** — Extract code/data availability statements
- **Bookmarks** — Save papers locally (no account needed)

## Quick Start

### Web UI
```
https://arxivexplorer.workers.dev/search?q=transformers+attention
```

### API (if exposed)
```bash
curl "https://arxivexplorer.workers.dev/api/search?q=attention+mechanisms&limit=10"
```

### CLI Tool
```bash
npm install -g @arxiv-explorer/cli
arxiv search "neural architecture search"
```

## Search Query Examples

- `"vision transformers for medical imaging"`
- `"reinforcement learning sample efficiency"`
- `"diffusion models inpainting"`
- `"formal verification neural networks"`

Semantic search understands synonyms, concepts, and research context.

## Technology Stack

- **Frontend:** Next.js 16, Tailwind, Three.js
- **Backend:** Cloudflare Workers
- **Database:** Cloudflare D1 (SQLite)
- **Vector Search:** Cloudflare Vectorize
- **Embeddings:** BGE base v1.5 (768-dim)
- **Summaries:** Llama 3.1 (Workers AI)
- **Hosting:** Cloudflare Pages

Runs entirely on Cloudflare's free tier.

## Features

### Semantic Search
Find papers by meaning, not keywords. Query expansion, typo-tolerance, concept matching.

### AI Summaries
Every paper gets a 2-3 sentence LLM summary highlighting contributions and methods.

### Topic Navigation
Browse by arXiv categories:
- cs.AI, cs.LG, cs.CV, cs.CL, cs.NE
- stat.ML, physics, math, econ

### Author Pages
See all papers by a specific researcher, sorted by date.

### Paper Compare
Side-by-side diff of abstracts, authors, categories. Spot differences in similar papers.

### Reproducibility Tracking
Extracts code/data availability claims from papers.

### Citation Graph
Who cites what — track influence and related work.

## Data Coverage

Currently indexes papers from major ML/AI categories. Ingestion runs daily via Cloudflare Workers cron.
